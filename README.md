# FORMA Earth & Art – Website

Website des FORMA Töpferstudios in Mathon (www.forma-pottery.com).

- `index.html` – die gesamte Seite
- `img/` – Fotos und Logo
- `video/` – Studio-Videos
- `fonts/` – Schriften (Bricolage Grotesque, Italiana, Outfit; SIL Open Font License)

Änderungen auf dem Branch `main` werden automatisch von Hostinger übernommen.
